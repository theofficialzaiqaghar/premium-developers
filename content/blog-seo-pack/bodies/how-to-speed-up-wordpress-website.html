If you need to speed up a WordPress website, start with measurement—not random plugin installs. Performance work should follow data from real URLs, devices, and traffic patterns.

High-impact optimisations

  • Images: modern formats, correct dimensions, lazy loading below the fold
  • Caching: page cache and object cache where hosting supports it
  • Plugins: remove unused plugins; audit page builders on critical URLs
  • Hosting: adequate CPU/RAM and a supported PHP version
  • Fonts: limit families and weights; preload only critical assets
  • Database: clean revisions and expired transients on large sites

Core Web Vitals mindset

Focus on LCP (largest content), INP (interactivity), and CLS (layout stability). Fix the specific element flagged in reports—hero images and third-party scripts are frequent culprits on UK business sites.

Step-by-step testing workflow

  1. Run PageSpeed Insights on the homepage and top landing pages
  2. Test logged-out and logged-in states separately
  3. Document baseline metrics
  4. Apply one change category (e.g. images) and retest
  5. Validate forms and checkout after caching changes

When to get professional help

WooCommerce catalogues, multilingual sites, or strict ad landing scores often need developer-led audits. Pair speed work with a redesign if UX and performance must improve together.
